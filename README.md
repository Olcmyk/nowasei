# No Wasei Skill

一个帮助 AI 在中文交流时避免使用和制汉语的 Claude Code skill。

## 什么是和制汉语？

和制汉语是明治维新时期日本创造的汉字词汇，后传入中国成为现代汉语的重要组成部分。例如：科学、哲学、经济、社会、民主等词汇都是和制汉语。

## 安装

```bash
npx skills add github:booffaoex/nowasei
```

## 使用

在对话中调用：
```
/no-wasei
```

或明确告诉 AI：
```
请使用 no-wasei skill 回答这个问题
```

## 功能

- 提供 20+ 个常用和制汉语的原生汉语替代词表
- 实用主义原则：在可读性和纯粹性之间平衡
- 适合追求古典韵味或语言纯粹性的写作场景

## 示例

**使用和制汉语：**
> 现代科学技术的发展促进了经济增长，社会进步明显，民主制度不断完善。

**避免和制汉语：**
> 当今格致之学的进境促进了生计改善，世道日新，民权制度渐趋完备。
