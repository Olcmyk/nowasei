# No Wasei Skill - 不用和制汉语，说大白话

一个让 AI 用中文交流时完全避免和制汉语、改用口语化大白话的 Claude Code skill。

## 什么是和制汉语？

和制汉语是明治维新时期（1868-1912）日本创造的汉字词汇，用于翻译西方概念。这些词后来传入中国，成为现代汉语的重要组成部分。

**常见的和制汉语：**
- 科学、技术、哲学、经济、社会、民主、革命、政治
- 文化、教育、知识、概念、抽象、具体、积极、消极
- 组织、计划、时间、空间、关系、问题、目的、手续
- 等等...几乎所有现代术语都是和制汉语

## 这个 Skill 做什么？

**不是**把和制汉语换成文言文或古词 ❌  
**而是**用大白话、土话、口语重新说一遍 ✅

### 对比示例

**使用和制汉语：**
> 现代科学技术的发展促进了经济增长，社会进步明显，民主制度不断完善。

**用大白话说：**
> 现在各种新办法、新手艺越来越多，大伙儿挣钱更容易了，日子过得比以前好多了，老百姓说话也更管用了。

**使用和制汉语：**
> 美国与伊朗的冲突涉及复杂的地缘政治因素和历史问题。

**用大白话说：**
> 美国跟伊朗闹矛盾，是因为一堆事儿，有以前的旧账，也有现在抢地盘的事。

## 安装

```bash
npx skills add github:Olcmyk/nowasei
```

## 使用

在对话中调用：
```
/no-wasei
```

或明确告诉 AI：
```
请使用 no-wasei skill 回答
```

## 特点

- ✅ **90+ 个常用和制汉语替换表**：覆盖日常最常用的词汇
- ✅ **口语化表达**：像跟邻居唠嗑一样自然
- ✅ **强制执行规则**：零容忍，一个和制汉语都不留
- ✅ **反 rationalization 机制**：堵住所有"这个词太常用"的借口
- ✅ **实战验证**：能够处理复杂话题（哲学、社会问题等）

## 适用场景

- 追求语言纯粹性的写作
- 让内容更接地气、更易懂
- 语言学习和研究
- 体验完全口语化的中文表达
- 了解现代汉语中和制汉语的渗透程度

## 实战效果

这个 skill 经过实战测试，能够：
- ✅ 用大白话讨论阶级固化等社会问题
- ✅ 用大白话讨论哲学问题（世界的真实性）
- ✅ 用大白话讲解复杂理论（如拉康的精神分析理论）

## 注意事项

这个 skill 采取**严格模式**：
- 一个和制汉语都不许用
- 所有句子都要改写成口语化表达
- 可能会让表达变长，但更通俗易懂

## 背景知识

据学者研究，现代汉语中约 **70% 的社科术语源自日语**。这些词已经完全融入现代汉语，以至于很多人都不知道它们其实来自日本。

本 skill 提供了一个有趣的实验：如果完全避免和制汉语，我们该如何用中文表达现代概念？
