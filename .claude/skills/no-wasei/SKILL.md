# 避免和制汉语

## 概述

用中文交流时，尽量使用原生汉语词汇，避免从日语传入的和制汉语。和制汉语是明治维新时期日本创造的汉字词汇，虽然在现代汉语中普遍使用，但存在更地道的原生汉语替代。

## 何时使用

- 用户明确要求避免和制汉语
- 需要使用更古典或传统的汉语表达
- 追求语言纯粹性的写作场景

## 常用替换表

| 和制汉语 | 原生汉语替代 |
|---------|------------|
| 科学 | 格致、学问 |
| 哲学 | 义理之学、穷理 |
| 经济 | 生计、理财 |
| 社会 | 世道、民间 |
| 革命 | 鼎革、变革 |
| 政治 | 政事、朝政 |
| 民主 | 民权、众治 |
| 自由 | 自在、任意 |
| 权利 | 权益 |
| 义务 | 本分、职责 |
| 物理 | 格物、物性之学 |
| 化学 | 舍密、质学 |
| 概念 | 观念、意念 |
| 抽象 | 虚理 |
| 具体 | 实在 |
| 积极 | 主动、力行 |
| 消极 | 被动、不为 |
| 组织 | 团体、机构 |
| 手续 | 程序、章程 |
| 场合 | 情形、境况 |

## 实施原则

1. **可读性优先**：如果原生替代过于生僻，保留和制汉语
2. **语境适配**：古典文体多用原生词，现代口语可适当保留
3. **不追求绝对**：完全避免和制汉语会严重影响表达，适度替换即可
4. **专业术语例外**：数学、科学的专业术语难以替代时可保留

## 常见问题

**"完全避免和制汉语无法交流"**
→ 正确。目标是"尽量"而非"完全"，保持表达流畅性。

**"原生替代词太古旧"**
→ 根据语境选择。现代口语对话中可以保留常用和制汉语。

**"科学术语怎么办"**
→ 专业术语如"物理"、"化学"可以保留，或用"物性之学"等文雅替代。

## 示例

**使用和制汉语：**
> 现代科学技术的发展促进了经济增长，社会进步明显，民主制度不断完善。

**避免和制汉语：**
> 当今格致之学的进境促进了生计改善，世道日新，民权制度渐趋完备。

## 注意事项

- 这是语言风格选择，不是语言正确性问题
- 70%的现代汉语社科术语源自日语，完全避免会严重影响交流
- 适用于追求古典韵味或语言纯粹性的特定场景
